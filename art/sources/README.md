# Base anatômica dos guardas

`human-base.obj`: base oficial do MakeHuman, obtida do [repositório oficial](https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj).

Licença **CC0**, explicitamente indicada no cabeçalho do OBJ. [Licenciamento dos assets MakeHuman](https://static.makehumancommunity.org/about/license.html). Os nomes dos titulares na liberação de setembro de 2020 constam no próprio arquivo. Nenhum código do aplicativo MakeHuman foi incorporado ao site.

Usada como fonte para cabeça e mãos, com simplificação e pose próprias. Vestuário, equipamentos e montagem foram criados para este projeto. O OBJ não é servido como recurso da página; o navegador recebe apenas o GLB vestido e otimizado.
